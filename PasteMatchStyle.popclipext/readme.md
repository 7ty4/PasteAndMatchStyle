# Paste & Match Style

Pastes clipboard content while matching the formatting of the surrounding text, using the standard macOS "Paste and Match Style" shortcut (⌥⇧⌘V).

## How it works

This extension sends the ⌥⇧⌘V key combination directly to the frontmost app. It's a thin wrapper around the OS-level "Paste and Match Style" shortcut, so it works in any app that already supports that shortcut natively (Pages, Mail, Notes, most Electron apps, etc.).
